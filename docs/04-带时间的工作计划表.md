# 桌面智能创作助手（码字工具）｜带时间的工作计划表
文档版本：v2.0（重定位·激进瘦身）
> 总周期：8 周，合计 56 自然日；业余开发每日可投入 1‑2 小时；周末集中做阶段验收、集成测试、文档。
> 技术方案：Spring Boot 3.5 + Spring AI 1.x GA（Spring AI 2.0 GA 要求 Spring Boot 4 基线，与本项目不兼容，锁定 1.x）+ **Electron 桌面壳（Vue3 + Element Plus）** + **SQLite（四表）** + Ollama；后端与 jlink 裁剪 JRE 随桌面安装包分发，**v1.0 仅交付 Windows x64**。
> 🔵v2.0 变化：产品重定位为**码字工具 + AI 赋能**；**移除**多 Agent FSM、写文件人工审批、本地文档 RAG、多会话隔离、Redis 快照、pgvector；数据层由六表收敛为 **SQLite 四表**（document / doc_version / prompt_template / material，单文件嵌入式），**去掉 Redis**；SSE 事件白名单收敛为 **token / error / complete**；阶段由 8 段重型设计重构为「写作核心（W1‑W4）→ AI 赋能（W3‑W7）→ 交付（W8）」。
> 全部里程碑对应 Git Tag：v0.1、v0.2、v0.3、v0.4、v0.5、v0.6、v0.7、v1.0。
> 文档包含：阶段总览、按天详细任务表格、里程碑定义、里程碑总览、文本甘特图、完整风险清单、MVP 阻塞降级裁剪预案、交付物清单、进度管控规则、迭代路线图。

> 2. 本地 Ollama 模式**需要用户自己安装 Ollama 并下载已经预训练完成的开源模型；不需要训练模型**；
> 3. 不想折腾软件安装，直接填入自有 API-Key 即可完整使用全部功能；
> 4. 文档/版本/模板/素材存本机 SQLite 单文件（**数据即本地文件**）；无需安装数据库服务，建议定期复制该 `.db` 文件备份；
> 5. v1.0 无法做按用户 API-Key 独立配额统计，配额请去第三方服务商控制台查看；
> 6. 联网素材需第三方搜索 API（外部依赖），未配置时开关置灰，不影响其他功能；
> 7. v1.0 不提供多 Agent 自动编排、本地文档 RAG、多会话隔离；
> 8. **平台声明：v1.0 桌面安装包仅交付 Windows x64（Windows 10/11）**，macOS / Linux 不在 v1.0 范围内；安装包内置 jlink 裁剪 JRE，**用户无需预装 JDK**。
